# 查寝小帮手Ultra 🧹📊

一个基于正态分布随机生成合理寝室卫生评分的 GUI 工具，适用于学生会/宿管部模拟检查数据。请注意，此软件仅供交流学习使用，不当使用该软件造成的一切后果由使用软件者自行承担，作者不承担任何责任。使用软件前请确保您个人具备完全民事行为能力。

## ✨ 功能特点
- 图形界面操作，无需编程基础
- 自定义评分区间，正态分布生成总分
- 逼近算法确保各项小分合理
- 按管理学院院公检记录表版式导出 Excel：寝室横向排列，包含检查信息、分项、备注和总分

## 📦 安装与运行
### 方式一：直接运行源码
1. 确保安装 Python 3.9+
2. 安装依赖：`pip install pandas openpyxl numpy`
3. 运行：`python 查寝小帮手ultra.py`

### 方式二：直接下载exe文件运行（建议没有任何环境配置、没有技术基础的Windows OS用户操作）

### macOS请运行源代码，本软件适配了macOS.

## 🖥️ 使用说明
1. 填写检查日期、人员、所属年级和随机种子（相同种子结果可复现）
2. 设置评分区间（最低分、最高分）
3. 输入寝室号（每行一个）
4. 点击“生成评分表格”，选择保存位置

导出文件使用单工作表，按实际寝室数量生成寝室列；备注默认填写“无”。程序在脚本内生成表格样式，无需另行分发参考工作簿。

# 寝室卫生检查评分系统 🧹📊

一个基于正态分布随机生成合理寝室卫生评分的 GUI 工具，适用于学生会/宿管部模拟检查数据。请注意，此软件仅供交流学习使用，不当使用该软件造成的一切后果由使用软件本人自行承担。

## ✨ 功能特点
- 图形界面操作，无需编程基础
- 自定义评分区间，正态分布生成总分
- 逼近算法确保各项小分合理
- 导出为 Excel 表格，便于存档分析

## 📦 安装与运行
### 方式一：直接运行源码
1. 确保安装 Python 3.7+
2. 安装依赖：`pip install pandas openpyxl numpy`
3. 运行：`python 查寝小帮手ultra.py`

### 方式二：打包为 exe（可选）
`pyinstaller --onefile --windowed 查寝小帮手ultra.py`

## 🖥️ 使用说明
1. 填写检查日期、人员、随机种子（相同种子结果可复现）
2. 设置评分区间（最低分、最高分）
3. 输入寝室号（每行一个）
4. 点击“生成评分表格”，选择保存位置
